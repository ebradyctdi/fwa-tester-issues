Setup Instructions

  1. Create a new Google Sheet with a tab named "Orders" (or let the script create it)
  2. Add headers (row 1): PO Number | Part Number | Serial Number | Process | Receive Date | Repair Code | Ship Date
  3. Go to Extensions → Apps Script
  4. Paste the code from google-apps-script.js
  5. Deploy → New Deployment → Web App → Execute as: Me → Who has access: Anyone
  6. Copy the /exec URL and paste it above, then click Save & Test
